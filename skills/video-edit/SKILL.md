# 口播视频一键剪辑 SKILL v1.0（竖版 1080x1920）

> 每天录一条口播原片，按本标准一键剪出竖版成片：去气口 + 四行滚动字幕 + 视频日记封面。
> 录制一条过，剪辑一条过，不在这上面磨时间——视频是顺便做的。
>
> v1.0（2026-11-25 定版）：已用真实口播视频完整跑通并验收。实测成绩：首条成片上线当日 500 播放，拿到平台推荐。

## 适合谁

- 每天做口播、知识分享的短视频博主，想把剪辑变成固定流程而不是每天重新发明
- 有自己的 AI 助手（Claude Code、Cursor 等）可执行本 Skill 的人
- 认同“录一条过、剪一条过”：出镜者每天只录一遍，不返工、不精修

## 输入清单（缺一不可，不齐不开工）

1. 口播原片：出镜者本人录制（铁律：不代录、不以 AI 充数），竖屏 2160x3840（带 rotation=90），30fps
2. 当日日期 + 天数：封面右上按当日写，如 2026/11/25、Day001
3. 标题：两排，跟视频内容一致（第一排白色，第二排品牌强调色，见封面一节）

## 环境要求

- ffmpeg 8.x（剪辑、转场、字幕烧录、拼接）
- Python 3 + `sherpa-onnx` + `soundfile` + `Pillow`（转写、字幕生成、封面生成）
- SenseVoice 中文转写模型（sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8），use_itn=True
- 思源黑体 Regular / Bold（或同等无衬线中文字体）
- 工具脚本：`tools/`（`pipe.py` 切气口 → `gen_subs.py` 滚动字幕 → `render.py` 渲染内容 → `make_cover.py` 封面 → `prepend_cover.py` 拼成片）

## 执行流程

### 1. 拉原片，转写，定切点

- ffprobe 确认原片竖屏 2160x3840、30fps、时长。
- 静音检测：ffmpeg silencedetect（noise=-40dB，d=0.3）找静音 → 语音段（最短 0.2s，间隔 <0.15s 合并）→ 每段 SenseVoice 转写。
- 切点方案：**间隔 >0.5s 只留 0.15s 尾巴，≤0.5s 全留**。产出 `segments.json`（keeps 为原时间轴上的保留段）、`keeplist.txt`、`subs.srt`、`audio_16k.wav`。
- **文字以全音频转写为准**：对整条音频单独跑一次转写得全文，段级转写常有错字，须逐句听音校对（例：同音错字“割肉/过肉”“跌再多/叠再多”只能靠听音纠正）。字幕去掉纯语气词（呢/哎/哦/呃/啊），保留原意；保留段内的气口音留在音频里，只剪静音。

### 2. 滚动字幕（字幕布模式）

- 短语：全文拆成每句 ≤8 字的短语，按原时间轴标起止，再经 keeps 映射到剪后时间。
- 版式：**4 行滚动窗，左对齐 x=82**，槽位 y=[1080, 1190, 1360, 1480]。上一句小字在上、当前句大字居中带 ▶ 前缀、下一句小字、再下一句小字偏暗（约 60% 不透明度）。
- 字号：小字 80px，大字 140px；**大字按句限宽**：`min(140, int(140*954/实测宽))`，下限 110（7 字句约 115，6 字句约 132），超宽不换行、不缩小到看不清、不溢出。
- 颜色与描边：**纯白字 + 黑色投影（ASS Shadow 4），不加黑边（Outline 0）**。切换时 0.3s 平滑滑动，每句 5 个事件（滑入→上移→放大→缩小→滑出淡出）。
- ASS 时间一律 2 位百分秒（见铁律）。

### 3. 渲染内容

- 按 keeps 逐段 trim/atrim 后 concat → scale 1080:1920 → 烧录字幕 → libx264 crf20 preset medium，yuv420p，30fps，AAC 128k，faststart。
- 注意：4K HEVC 在普通云主机上解码约 0.09–0.15 倍速，全量渲染一次约 4–12 分钟，预算好时间。

### 4. 封面（视频日记模版）

- 模版：1080x1920，底图用当日视频帧。
- **固定不变**：左上品牌角标（示例：黄框 + 白字“视频日记”，配四角黄色引号框）；版权行（按自己的品牌写，如 `©Copyright 2026 你的品牌`），品牌强调色，常规体，字宽 263，x=72，字顶 y=465。
- **每日变量**：日期（白色粗体，字宽 304，右沿 x=999，字顶 y=225）+ 天数（白色粗体，字宽 432，右沿 x=1000，字顶 y=312）。
- 标题：第一排白色常规体（字宽 536，x=77，字顶 y=1214）；第二排品牌强调色粗体（字宽 956，x=73，字顶 y=1365；示例强调色：青色 #00FFFC）。**标题两排字号按字宽反推，不固定字号。**
- 全部文字黑软投影（模糊 + 下移），不加黑描边。
- 校验：生成图与模版逐项量过，标题 / 日期 / 天数 / 版权字顶与字宽误差 ≤4px 才算过。

### 5. 拼成片

- 封面 1.2s（静音 AAC）+ 内容，concat 拼合。
- **成片文件名每版不同，绝不重名覆盖**：`成片-视频日记DayNNN-<标题>.mp4`。旧版改名保留，不删。
- 输出 1080x1920，30fps，H.264 mp4，faststart。

## 验片（交付前必做，不验不发）

1. 从成片抽**新帧**验：封面一帧（t≈0.6）+ 内容一帧，确认封面元素齐全、字幕内容与时间对得上。**验片帧每次重抽，旧帧会误导。**
2. 字幕全程逐秒抽帧看一遍（contact sheet），不只抽几个点；空档与淡入处要对得上 ASS。
3. ASS 生成后 grep 核对：时间一律 2 位百分秒，每事件 Start < End。
4. 封面与模版逐项量字顶 / 字宽，误差 ≤4px。

## 铁律

- 原片必须是出镜者本人录的，画质 / 收音不合格打回重录，不硬剪。
- **ASS 时间一律 2 位百分秒**：3 位毫秒会被 libass 误读成百分秒（如 02.230 → 4.30s），字幕错位、串句、消失。生成后 grep 核对小数位数。
- **remap 吸附规则**：短语起止是手标的原时间，落在切掉的静音里时，映射到下一保留段的起点，不返回总时长（否则事件 Start > End 直接不渲染）。
- **concat 清单路径一律绝对路径**：相对路径会被 concat demuxer 按清单所在目录解析，拼出来只有封面 1.2s。
- **改版必换文件名**：同一文件名发两版，接收方极易打开旧版。
- 成片须经出镜者验收通过才算完；修改意见记回本 Skill 的迭代区。
- 每日一条是固定节奏：日期、天数、标题三个变量每天换，其它全部按本标准不动。
- **一条过**：录制一条过，剪辑一条过；按标准走不返工，不在这上面多花时间。
